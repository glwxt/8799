# 金融新闻收集项目 — 方法 V1.2

- 版本：V1.2，2026-11-19（新增：空间只留最近 3 天，3 天以前自动删除）
- 版本：V1.1，2026-11-19（新增：英文新闻中文翻译）
- 版本：V1.0，2026-11-18
- 系统关系：与每日全球金融市场简报、GLI、GLT、BTC 4小时追踪完全独立。不替换、不修改、不合并它们。简报给结论，新闻库留原材料：可回查、可按资产找、每条有来源和时间。
- 交付：只发独立空间「金融新闻收集」，不发聊天，不发邮件。

## 1. 收什么：六类

1. 宏观/央行：美联储、CPI/就业/通胀、利率、财政、主要央行
2. 美股 AI 半导体：英伟达及 AI 链、半导体、美股大盘与个股重大消息
3. 台股：加权指数、台积电及半导体链、外资动向
4. BTC 加密：BTC 现货、ETF 资金流、交易所、监管、稳定币
5. 黄金原油：黄金、原油及大宗商品、央行购金
6. 汇率资金流：DXY、USD/JPY、USD/CNY、USD/TWD、跨境资金流、ETF 流向

## 2. 来源分级

- 一级（优先）：官方公告、央行/财政部/交易所/监管机构、上市公司公告
- 二级：钜亨、Bloomberg、Reuters、WSJ、FT 等主流财经媒体
- 三级：X 公开快讯（公开搜索，不绑定账号；X 登录此前多次失败，见 MEMORY，不再盲目重试）

官方为准；同一事件只留一条，去重；二手转载须能追溯到一级或二级来源。

## 3. 每条记录字段

- 时间（北京时间，含原始发布时间）
- 来源机构及原文链接
- 标题（原文标题，不改写成结论）
- 一句话摘要（只写新闻说了什么，不做预测）
- 影响资产（从六类/具体标的中选，如 BTC、台积电、DXY）
- 重要度 1–5 星：5 星为可能改变市场方向的重大消息，1 星为一般资讯
- 类别标签（六类之一，可多选时以主类别为准）
- 中文翻译（仅英文等非中文新闻）：原文标题和摘要旁边各加一行中文翻译（中文字幕式，紧贴原文下方、样式略淡以区分）。标题翻译 + 摘要翻译都要有；中文新闻不加翻译。翻译只忠实转述原文，不加解读、不改数字/日期/人名/公司名/代码，专有名词首次出现可括号保留原文。翻译不确定时标“译文待核实”，不得凭空补全。

## 4. 质量规则

- 只报可核实的消息；无法验证标“待核实”，绝不编造数字、日期、来源或链接。
- 不做预测、不给投资建议；摘要与结论分开，新闻库本身不下方向判断。
- 标题、数字、时间以原文为准；转载与原文冲突时以官方/原文为准并注明。
- 免费模型规则（沿用简报/GLI/GLT）：免费模型只起草摘要与分类，Muse 逐句核验，删掉任何新编数字、日期或来源；不得拖延每批的保存时间。

## 5. 更新节奏

- 每天三批：08:00、13:00、21:30（台湾时间，约数，不承诺精确分钟）
- 每批 5–8 条，一天 15–25 条；无重大新闻时宁缺毋滥，不凑数
- 重大突发（5 星）即时补一条，不等下一批
- 每批保存一个文件：~/workspace/goals/goal-3/files/YYYY-MM-DD-news-HHMM.md；当日汇总由空间按时间倒序展示
- 保留期限（V1.2，2026-11-19 修正）：空间只留最近 3 天的新闻，发表时间超过 3 天的在每次定时刷新时自动从空间中删除，不用手动一条条删。已收藏的新闻不被自动删除（收藏可延长保留）；未收藏的超过 3 天自动删除。删除只针对空间里的展示库，每批保存的 ~/workspace/goals/goal-3/files/ 文件档案不受影响，仍可回查。

## 6. 空间呈现

- 手机友好：首屏先显示今日重大 5 条（4–5 星），下面按时间倒序列全部
- 筛选：按类别（六类）与按影响资产筛选；支持按日期回看
- 每条可点原文链接；加载要快，首屏不依赖重图表
- 报告区在首期收集前为“待发布”状态，不编造新闻占位
