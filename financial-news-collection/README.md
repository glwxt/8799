# 金融新闻收集

独立运行的金融新闻收集项目，与每日全球金融市场简报、GLI、GLT、BTC 4 小时追踪完全独立，不替换、不修改、不合并它们。简报给结论，新闻库留原材料：可回查、可按资产找、每条有来源和时间。

- 目标 ID：`goal_3d0f1598f79d`（Muse 内）
- 空间：Muse 空间「金融新闻收集」，slug `jin-rong-xin-wen-shou-ji`
- 交付：只发空间，不发聊天，不发邮件
- 方法版本：V1.2（2026-11-19，见 `docs/news-collection-methodology.md`）

## 收什么：六类

1. 宏观/央行：美联储、CPI/就业/通胀、利率、财政、主要央行
2. 美股 AI 半导体：英伟达及 AI 链、半导体、美股大盘与个股重大消息
3. 台股：加权指数、台积电及半导体链、外资动向
4. BTC 加密：BTC 现货、ETF 资金流、交易所、监管、稳定币
5. 黄金原油：黄金、原油及大宗商品、央行购金
6. 汇率资金流：DXY、USD/JPY、USD/CNY、USD/TWD、跨境资金流、ETF 流向

## 每条记录字段

时间（北京时间）、来源机构及原文链接、标题（原文标题）、一句话摘要（只写新闻说了什么，不做预测）、影响资产、重要度 1–5 星、类别标签。英文等非中文新闻：标题和摘要旁边各加一行中文翻译，紧贴原文下方；中文新闻不加翻译。

## 更新节奏

每天三批，每批 5–8 条，一天 15–25 条；无重大新闻时宁缺毋滥，不凑数。5 星重大突发即时补一条，不等下一批。

| 批次 | 收集（Muse 定时任务） | 空间刷新 |
| --- | --- | --- |
| 早上 | 约 08:11 | 约 09:02 |
| 中午 | 约 13:33 | 约 14:38 |
| 晚上 | 约 22:00 | 约 22:45 |

任务说明见 `tasks/`。注意：空间刷新必须跑在收集之后。2026-11-19 曾出过时间差问题：中午刷新 13:24 跑在中午收集 13:37 之前、晚上刷新 21:49 跑在晚上收集 22:00 之前，导致收了但空间看不到；已把中午刷新改到约 14:38、晚上刷新改到约 22:45，早上刷新约 09:02 不变。

## 保留期限

空间只留最近 3 天的新闻，发表时间超过 3 天的在每次定时刷新时自动从空间中删除。已收藏的新闻不被自动删除。删除只针对空间里的展示库，`data/` 里的每批文件档案不受影响，仍可回查。

## 来源分级与质量规则

- 一级（优先）：官方公告、央行/财政部/交易所/监管机构、上市公司公告
- 二级：钜亨、Bloomberg、Reuters、WSJ、FT 等主流财经媒体
- 三级：X 公开快讯（公开搜索，不绑定账号、不登录）
- 官方为准；同一事件只留一条，去重；无法验证标“待核实”，绝不编造数字、日期、来源或链接；不做预测、不给投资建议。
- 免费模型只起草摘要、分类与中文翻译，Muse 逐句核验，429、超时或含编造内容直接跳过，不得拖延每批的保存时间。

## 仓库里有什么、没有什么

有：

- `docs/news-collection-methodology.md` — 方法 V1.2（六类、来源分级、字段、质量规则、节奏、保留期限）
- `tasks/` — 三批收集任务的执行说明（窗口、去重、保存路径）与空间刷新时间表
- `data/` — 每批新闻的档案文件，`YYYY-MM-DD-news-HHMM.md`，首批 2026-11-19 三批

没有（诚实说明，免得以后误会）：

- 空间本身的前端/后端源码：空间是 Muse 里的 fullstack 空间（slug `jin-rong-xin-wen-shou-ji`），源码由 Muse 托管，不能导出成可运行代码，仓库里存的是它的规格与数据，不是可直接部署的复刻。
- Muse 的定时任务本身：`tasks/` 是任务的文字说明，定时运行仍在 Muse 里，不是从这个仓库跑的。
- 任何密钥：仓库里没有任何 API key、密码或 token。OpenRouter 免费模型调用走 Muse 的安全存储。

## 以后怎么维护

- 方法改了：更新 `docs/news-collection-methodology.md`，版本号 +1，并同步改 `tasks/` 里的对应说明。
- 每天的新批次：把当天的 `YYYY-MM-DD-news-HHMM.md` 加进 `data/`。
- 刷新时间再出时间差：先核对收集任务的实际完成时间，再把对应刷新改到收集之后。
