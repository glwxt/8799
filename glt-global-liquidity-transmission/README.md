# GLT 全球流动性传导与资产配置监测

独立运行的全球流动性传导与资产配置监测系统（GLT），与 GLI 全球流动性综合监测完全独立，不替换、不修改、不合并 GLI。GLI 回答“流动性总量是改善还是收紧”，GLT 回答“流动性有没有传导到金融市场、资金最终流向哪些资产”。

## 四层 100 分体系

| 层 | 权重 | 内容 |
| --- | --- | --- |
| 流动性供给 | 30 | 银行准备金 8、TGA 8、ON RRP 5、美联储资产负债表 5、全球美元流动性 4 |
| 金融条件 | 25 | DXY 8、10 年期实际利率 8、10 年期名义收益率 4、美元融资压力 5 |
| 风险偏好 | 20 | VIX 5、高收益债利差 5、美股广度 4、避险需求 3、全球市场波动 3 |
| 实际资金流向 | 25 | BTC 7、黄金 6、美股 6、亚洲股票 4、债券 2 |

每项指标 0–100 分，50 为中性；DXY、实际利率、VIX、信用利差反向评分；TGA、ON RRP、名义收益率、避险需求按上下文解释方向。综合分 = 供给×30% + 金融条件×25% + 风险偏好×20% + 资金流向×25%。

状态区间：80–100 强势宽松；65–79 温和宽松；45–64 中性震荡；30–44 温和收紧；0–29 强势收紧。分数不是上涨概率。

另有三个资产独立评分 BTC-GT、GOLD-GT、EQUITY-GT，各 0–100 + 偏多/中性/偏空，不与总分重复相加；以及背离预警（一级观察 / 二级警示 / 三级风险）。

## 数据完整性规则（方法 5.5）

- 单层覆盖其层内权重 <80%：不发该层正式分
- 总覆盖 <80%：不发综合分，只发定性判断
- 覆盖 80–90%：标注“部分数据”并降低置信度
- 缺失不填 0、填 50 或沿用旧值；无法验证标 NA / 待核实，绝不编造
