# GOLD-GT 首轮样本外验证

研究日期 2026-11-24（台湾时间），历史数据截止 2026-11-20。首次验证目标为 GLD 下一交易日与未来五个交易日的收盘对数收益。两种期限是 24 小时和 7 天的交易日近似。

## 口径和复现

- GLD 收盘及黄金总盎司、每份黄金盎司取自发行人历史档案。以总盎司除以每份盎司推算流通份额，再取五个交易日变化。仅用于单基金申赎方向代理，未用市值或吨数变化冒充全球 ETF 美元净流。份额推算有取整和披露时点误差；指标至少滞后一个 GLD 交易日。
- 美国 10 年实际利率用 DFII10，取五个观测日变化，输入最迟为前一 GLD 交易日。美元用 H.10 广义名义美元指数 DTWEXBGS，取五个观测日变化；因日度值按周发布，至少滞后十个日历日，同时剔除超时效输入。此为广义美元代理，不替代方法中的 ICE DXY。
- 所有历史数据为本次获取的版本，未逐日确认历史首次发布时间或修订。上述滞后用于减少前视风险。结果属探索性样本外验证，正式启用前需按原始披露版本复跑。
- 每月重估扩展训练，训练标签结束日期须早于测试月首个信号日期。对比历史平均收益、加入实际利率和美元的岭回归、再加入 GLD 份额代理的岭回归。惩罚系数为 1，仅以训练数据标准化。

## 结果

2019 年至截止日。平均绝对误差单位为基点。方向命中按预测与实际收益符号相同计；方向基准会受样本上涨占比影响。

| 期限 | 样本 | 历史均值误差 / 命中 | 利率和美元误差 / 命中 | 另加 GLD 份额误差 / 命中 |
| --- | ---: | --- | --- | --- |
| 1 个交易日 | 1983 | 80.52 / 54.16% | 80.58 / 53.30% | 80.67 / 52.14% |
| 5 个交易日 | 1979 | 182.20 / 56.75% | 183.03 / 55.89% | 183.20 / 55.94% |
| 5 个交易日，非重叠 | 396 | 182.59 / 56.31% | 183.48 / 55.81% | 183.80 / 56.06% |
| 1 个交易日，2024 年起 | 725 | 101.17 / 56.00% | 101.17 / 56.00% | 101.22 / 55.17% |
| 5 个交易日，2024 年起 | 721 | 225.35 / 59.50% | 225.38 / 59.50% | 225.68 / 59.50% |

现有特征组合未优于历史均值。加入 GLD 份额代理后，两个期限的误差均上升；五日方向命中仅略有改善且仍低于历史均值。该结论只适用于此单基金代理和当前口径，不能外推至全球 ETF 实际净流。

GOLD-GT 正式评分维持空值。下一轮需要锁定可按披露时点取得的多基金实际净流和真正的 DXY 历史口径，再以独立样本及既有基准验证；对年度、月度等低频因素按实际披露期另行处理。
