# 流动性供给层 V1.1 候选信号初筛

2026-11-24。研究样本取自 2026-05-21 至 2026-11-19 的 27 期 H.4.1 原始发布页。CSV 保留逐期来源和发布日期。准备金、供给及吸收因素、TGA、H.4.1 其他逆回购均使用周均变化；总资产使用周三时点变化。供给减吸收与公布的准备金变动最大差额为 2 百万美元。此研究按发布日期的期序推进，未声称精确发布时刻已验证。

以本期发布的准备金变化预测下一期公布的准备金变化。首 12 个已完成预测对用于初训，此后逐期扩展训练并预测下一期，得到 14 个样本外结果。每折标准化参数仅由该折训练样本计算。比较准备金单变量和每次增加一个候选的岭回归，标准化后惩罚系数为 1，截距不惩罚。该设计是探索性初筛，尚无独立确认样本。运行方式为 `python evaluate.py h41.csv`，依赖 NumPy。

| 模型 | 平均绝对误差（十亿美元） | 方向命中 |
| --- | ---: | ---: |
| 准备金基线 | 43.24 | 6/14 |
| 加入 TGA | 42.03 | 9/14 |
| 加入 H.4.1 其他逆回购 | 45.12 | 9/14 |
| 加入美联储总资产 | 47.47 | 5/14 |

TGA 在这 14 期内误差下降约 2.8%，仅作为优先复验候选。其他逆回购方向命中改善但误差扩大，该变量是 H.4.1 分类代理，不能替代纽约联储 ON RRP 操作序列或证明资金去向。总资产变化单变量增量在本轮未得到支持，表 5 周三变动与周均准备金各保留原频率口径。下一轮应固定本次评价规则，在独立期间复验，并为准备金评分补足历史校准、为 ON RRP 使用操作数据、为资产端检验政策或持仓结构变量。本记录不改变 V1.0 引擎，也未向任何正式评分表写入得分。
